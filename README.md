# AuditoryProcessingSleepingInfant

This repository contains the code and Jupyter notebook used to analyze an EEG dataset of sleeping infants in
a passive auditory paradigm.   

The project is organized into the following directories:

```text
EEG_PROJECT
├── config/   
├── figures/
├── notebooks/
├── src/
└── README.md
```

### config

This folder contains subjects numbers and inclusion/exclusion mask, in addition to electrodes indices used for different analyses.

### figures

Main figures generated from the analysis pipeline.

### notebooks

Jupyter notebook used in the analysis.

### src

Python modules containing reusable functions for data processing, analysis, and visualization.

The EEG dataset is not included in this repository.
